# Chamidu Sandeepa — Portfolio

A Next.js App Router portfolio with TypeScript, Tailwind CSS 4, and Motion for React.

## Run locally

```bash
npm install
npm run dev
```

Open http://localhost:3000.

## Build

```bash
npm run build
npm start
```
